# Алгоритми за сортиране

## 0. Някои основни характеристики на сортиращите алгоритми:

* Сложност по време:

**Дефиниция:** сложността по време описва как се променя броят на операциите, които алгоритъмът извършва, спрямо броя на входните елементи N. Тя ни помага да оценим ефективността на алгоритъма при различни размери на входните данни.

* Сложност по памет:

**Дефиниция:** сложността по памет описва как се променя количеството памет, необходимо на алгоритъма по време на изпълнение, спрямо размера на входните данни. Допълнителната пространствена сложност отчита паметта, използвана извън тази на входните данни.

* Стабилност:

**Дефиниция:** Стабилността е свойство на алгоритмите за сортиране, при което елементите с еднакви стойности по критерия на сортиране запазват първоначалния си относителен ред след сортирането.

**Пример:**

Нека имаме списък от ученици, предварително подреден лексикографски по име. Искаме да сортираме учениците по оценка във възходящ ред, като запазим лексикографския ред между учениците с еднакви оценки.

**Преди сортиране (лексикографски по име):**

| Име | Оценка |
|---|---:|
| Анна | 5 |
| Борис | 4 |
| Виктор | 5 |
| Георги | 3 |
| Мария | 4 |

**След стабилно сортиране по оценка:**

| Име | Оценка |
|---|---:|
| Георги | 3 |
| Борис | 4 |
| Мария | 4 |
| Анна | 5 |
| Виктор | 5 |

Забелязваме, че учениците с еднакви оценки запазват първоначалния си лексикографски ред: Борис остава преди Мария, а Анна — преди Виктор.

## 1. Bubble Sort

**Концепция:** Основната идея на Bubble Sort е, че при всяко преминаване през масива най-големият елемент от несортираната част постепенно „изплува“ надясно, докато достигне края ѝ. 

За целта обхождаме масива отляво надясно, като сравняваме всеки елемент със следващия(разглеждаме елементите на масива по двойки). Ако текущият елемент е по-голям, разменяме двата елемента, така че по-големият да остане вдясно. След това продължаваме обхождането от следващата позиция. Така по-големият елемент участва в следващото сравнение и, ако отново е по-голям от елемента след него, се премества още една позиция надясно. Този процес продължава, докато най-големият елемент достигне края на несортираната част на масива. 

След всяко пълно преминаване най-големият елемент от несортираната част заема правилната си позиция. Затова при всяко следващо преминаване можем да пропускаме най-десните, вече сортирани елементи, и да продължаваме със същия процес върху останалата несортирана част на масива.

Визуализация на Bubble sort върху масива `{5, 3, 8, 1, 2}`:

![Bubble Sort анимация](images/bubble_sort.svg)

Код:

```cpp
#include <vector>
#include <utility>

void bubbleSort(std::vector<int>& v) {
    int n = v.size();

    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;

        for (int j = 0; j < n - 1 - i; j++) {
            if (v[j] > v[j + 1]) {
                std::swap(v[j], v[j + 1]);
                swapped = true;
            }
        }

        if (!swapped) {
            break;
        }
    }
}
```

Сложност:

| време | памет |
| :--- | :--- |
| $O(N^2)$ | $O(1)$ |

* С оптимизацията със `swapped` best case става $O(N)$
* Алгоритъмът е стабилен.

## 2. Selection Sort

**Концепция:** Основната идея на Selection Sort е, че при всяко преминаване през масива намираме най-малкия елемент от несортираната част и го поставяме на първата позиция в нея.

За целта обхождаме несортираната част на масива отляво надясно, като сравняваме елементите и запомняме позицията на най-малкия елемент, който сме открили до момента. Продължаваме обхождането, докато достигнем края на несортираната част и намерим най-малкия елемент в нея.

След това разменяме местата на намерения най-малък елемент с първия елемент от несортираната част. Така най-малкият елемент заема окончателната си позиция в началото на масива.

При всяко следващо преминаване пропускаме вече сортираните елементи в началото и повтаряме същия процес върху останалата несортирана част. Алгоритъмът продължава, докато всички елементи заемат правилните си позиции.

Анимация на Selection sort върху масива `{5, 3, 8, 1, 2}`:

![Selection Sort анимация](images/selection_sort.svg)

Код:

```cpp
#include <vector>
#include <utility>

void selectionSort(std::vector<int>& v) {
    int n = v.size();

    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;

        for (int j = i + 1; j < n; j++) {
            if (v[j] < v[minIdx]) {
                minIdx = j;
            }
        }

        if (minIdx != i) {
            std::swap(v[i], v[minIdx]);
        }
    }
}
```

Сложност:

| време | памет |
| :--- | :--- |
| $O(N^2)$ | $O(1)$ |

* Алгоритъмът е нестабилен.

## 3. Insertion Sort

**Концепция:** Основната идея на Insertion Sort е да сортираме масива постепенно, като вземаме по един елемент от несортираната част и го вмъкваме на правилната му позиция сред вече сортираните елементи.

В началото приемаме, че първият елемент е сортиран, тъй като сам по себе си той не изисква подреждане. След това вземаме следващия елемент и го сравняваме с елементите от сортираната част, започвайки отдясно наляво. Докато срещаме елементи, които са по-големи от текущия, ги преместваме с една позиция надясно, за да освободим място за него.

Продължаваме, докато намерим елемент, който е по-малък или равен на текущия, или достигнем началото на масива. След това поставяме текущия елемент на освободената позиция. Така сортираната част на масива се увеличава с един елемент.

При всяка следваща стъпка повтаряме същия процес със следващия елемент от несортираната част, като го вмъкваме на правилното му място сред вече сортираните елементи. Алгоритъмът продължава, докато всички елементи бъдат включени в сортираната част и целият масив стане сортиран.

Анимация на Insertion sort върху масива `{5, 3, 8, 1, 2}`:

![Insertion Sort анимация](images/insertion_sort.svg)

Код:

```cpp
#include <vector>

void insertionSort(std::vector<int>& v) {
    int n = v.size();

    for (int i = 1; i < n; i++) {
        int key = v[i];
        int j = i - 1;

        while (j >= 0 && v[j] > key) {
            v[j + 1] = v[j];
            j--;
        }

        v[j + 1] = key;
    }
}
```

Сложност:

| време | памет |
| :--- | :--- |
| $O(N^2)$ | $O(1)$ |

* Алгоритъмът е стабилен.

## 4. Merge Sort

**Концепция:** Основната идея на Merge Sort е да сортираме масива, като го разделяме на по-малки части, докато всяка част съдържа само един елемент, а след това постепенно ги обединяваме в сортирани подмасиви.

За целта разделяме масива на две приблизително равни части и повтаряме същия процес рекурсивно за всяка от тях, докато достигнем подмасиви с по един елемент. Тъй като подмасивът с един елемент вече е сортиран, можем да започнем процеса на обединяване.

При обединяването сравняваме първите необработени елементи на двата сортирани подмасива и преместваме по-малкия от тях в новия масив. След това продължаваме със следващия елемент от подмасива, от който сме взели елемент, като повтаряме сравненията, докато всички елементи от двете части бъдат обединени в правилния ред. Ако в единия подмасив останат елементи, ги добавяме към края на резултата, тъй като те вече са сортирани.

По този начин постепенно обединяваме малките сортирани части в по-големи, докато получим един цялостен сортиран масив. Алгоритъмът приключва, когато всички части бъдат обединени.

Анимация на Merge sort върху масива `{5, 3, 8, 1, 2, 7, 4, 6}`:

![Merge Sort анимация](images/merge_sort.svg)

Код:

```cpp
#include <vector>

void merge(std::vector<int>& v, int l, int m, int r, std::vector<int>& buf) {
    int i = l;
    int j = m + 1;
    int k = 0;

    while (i <= m && j <= r) {
        if (v[i] <= v[j]) {
            buf[k++] = v[i++];
        } else {
            buf[k++] = v[j++];
        }
    }

    while (i <= m) 
        buf[k++] = v[i++];

    while (j <= r) 
        buf[k++] = v[j++];

    for (int t = 0; t < k; t++) {
        v[l + t] = buf[t];
    }
}

void mergeSortStep(std::vector<int>& v, int l, int r, std::vector<int>& buf) {
    if (l >= r) return;

    int m = l + (r - l) / 2;
    mergeSortStep(v, l, m, buf);
    mergeSortStep(v, m + 1, r, buf);
    merge(v, l, m, r, buf);
}

void mergeSort(std::vector<int>& v) {
    std::vector<int> buf(v.size());
    mergeSortStep(v, 0, (int)v.size() - 1, buf);
}
```

Сложност:

| време | памет |
| :--- | :--- |
| $O(N \log N)$ | $O(N)$ |

* Алгоритъмът е стабилен.

## 5. Quick Sort

**Концепция:** Основната идея на Quick Sort е да сортираме масива, като избираме опорен елемент (pivot) и пренареждаме останалите елементи така, че по-малките да се намират отляво, а по-големите — отдясно.

За целта избираме средния елемент за пивот и използваме два указателя — единият започва от началото на масива и се движи надясно, докато намери елемент, който е по-голям или равен на пивота. Другият започва от края на масива и се движи наляво, докато намери елемент, който е по-малък или равен на пивота. Ако левият указател все още се намира преди десния, разменяме местата на намерените елементи и продължаваме обхождането. Така по-малките елементи постепенно се преместват наляво, а по-големите — надясно, докато масивът се раздели на две части.

След това прилагаме същия процес рекурсивно върху двете части, докато всяка съдържа най-много един елемент. Така постепенно целият масив се подрежда, без да е необходимо допълнително обединяване на частите.

Анимация на Quick sort върху масива `{2, 8, 7, 1, 3, 5, 6, 4}`:

![Quick Sort анимация](images/quick_sort.svg)

Код:

```cpp
#include <vector>
#include <utility>

int partition(std::vector<int>& v, int l, int r) {
    int pivot = v[l + (r - l + 1) / 2];
    int i = l;
    int j = r;

    while (i <= j) {
        while (v[i] < pivot) 
            i++;
        while (v[j] > pivot) 
            j--;

        if (i <= j) {
            std::swap(v[i], v[j]);
            i++;
            j--;
        }
    }

    return j;
}

void quickSort(std::vector<int>& v, int l, int r) {
    if (l >= r) 
        return;

    int p = partition(v, l, r);
    quickSort(v, l, p);
    quickSort(v, p + 1, r);
}
```

Сложност (среден случай):

| време | памет |
| :--- | :--- |
| $O(N \log N)$ | $O(\log N)$ |

* Алгоритъмът е нестабилен.

## 6. Counting Sort

**Концепция:** Основната идея на Counting Sort е да сортираме масива, като преброяваме колко пъти се среща всяка стойност, вместо да сравняваме елементите помежду им. След това използваме натрупаните броячи, за да определим правилната позиция на всеки елемент в сортирания масив.

Алгоритъмът преминава през три основни стъпки:

1. **Броене** — първо определяме диапазона от стойности в масива и създаваме помощен масив `count`, в който всяка позиция съответства на определена стойност. След това обхождаме оригиналния масив и увеличаваме брояча на съответната позиция всеки път, когато срещнем дадена стойност. Така установяваме колко пъти се среща всяка стойност.

2. **Натрупване** — след като преброяването приключи, преобразуваме помощния масив в кумулативен, като събираме брояча на всяка позиция с брояча на предходната: `count[i] += count[i - 1]`. По този начин всяка позиция показва общия брой елементи, които са по-малки или равни на съответната стойност. Това ни позволява да определим крайната позиция, на която трябва да бъде поставен елементът с тази стойност в сортирания масив. Тъй като броячите показват брой елементи, а не индекси, изваждаме единица, за да получим съответния индекс.

3. **Изграждане на сортирания масив** — обхождаме оригиналния масив отзад напред и използваме кумулативните броячи, за да поставим всеки елемент на правилната му позиция в нов масив. След поставянето намаляваме съответния брояч с единица, така че следващият елемент със същата стойност да бъде поставен на предходната свободна позиция. Обхождането отзад напред запазва първоначалния относителен ред на елементите с еднаква стойност, което прави тази реализация на алгоритъма стабилна.

След като всички елементи бъдат поставени на правилните си позиции, получаваме напълно сортиран масив. Накрая, ако е необходимо, прехвърляме елементите от новия масив обратно в оригиналния.

Анимация на counting sort върху масива `{4, 2, 0, 7, 1, 3, 2, 9}` (стойности 0–9, затова броячът е с 10 клетки):

![Counting Sort анимация](images/counting_sort.svg)

Код:

```cpp
#include <vector>
#include <algorithm>

void countingSort(std::vector<int>& v) {
    if (v.empty()) return;

    int maxVal = *std::max_element(v.begin(), v.end());
    std::vector<int> count(maxVal + 1, 0);

    for (int x : v) {
        count[x]++;
    }

    for (int i = 1; i <= maxVal; i++) {
        count[i] += count[i - 1];
    }

    std::vector<int> out(v.size());
    for (int i = (int)v.size() - 1; i >= 0; i--) {
        count[v[i]]--;
        out[count[v[i]]] = v[i];
    }

    v = out;
}
```

Сложност (нека $K$ е максималната стойност):

| време | памет |
| :--- | :--- |
| $O(N + K)$ | $O(N + K)$ |

* Алгоритъмът е стабилен.
* Работи, когато $K$ е разумно малък. Ако например числата са до $10^9$, ще ни трябва масив с милиард клетки — counting sort става неизползваем.

## 7. Radix Sort

**Концепция:**
Основната идея на Radix Sort е да сортираме числата, като обработваме техните цифри последователно — от най-малкозначителната към най-значителната, вместо да сравняваме самите числа помежду им.

За целта започваме от най-дясната цифра на всяко число, която съответства на единиците, и подреждаме числата според нейната стойност. За тази стъпка използваме стабилен алгоритъм за сортиране, обикновено Counting Sort, който запазва относителния ред на числата с еднаква текуща цифра.

След това повтаряме същия процес за следващата цифра — десетиците, стотиците и т.н. При всяко следващо преминаване числата се подреждат според текущата цифра, като благодарение на стабилността на Counting Sort се запазва редът, постигнат при предишните стъпки.

Алгоритъмът продължава, докато бъдат обработени всички цифри на най-голямото число. Така числата постепенно се подреждат според все по-значимите си цифри, докато получим напълно сортиран масив във възходящ ред.

## Кратко сравнение

| алгоритъм | време (среден случай) | памет | стабилен |
| :--- | :--- | :--- | :--- |
| Bubble Sort | $O(N^2)$ | $O(1)$ | да |
| Selection Sort | $O(N^2)$ | $O(1)$ | не |
| Insertion Sort | $O(N^2)$ | $O(1)$ | да |
| Merge Sort | $O(N \log N)$ | $O(N)$ | да |
| Quick Sort | $O(N \log N)$ | $O(\log N)$ | не |
| Counting Sort | $O(N + K)$ | $O(N + K)$ | да |
